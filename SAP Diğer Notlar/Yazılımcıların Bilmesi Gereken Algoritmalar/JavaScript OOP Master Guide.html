TEMEL

Class & Constructor

JS'de sınıflar birer "Syntactic Sugar"dır. Arka planda Prototype çalışır ama yazımı Java/C#'a benzer.

class Developer {
    constructor(ad, stack) {
        this.ad = ad;
        this.stack = stack;
    }

    kodYaz() {
        return `${this.ad} kodluyor...`;
    }
}
ES2022

Encapsulation (Private Fields)

Modern JS'de değişkenlerin başına # koyarak onları dış dünyaya kapatırız.

class BankaHesabi {
    #bakiye; // Private Değişken

    constructor(miktar) {
        this.#bakiye = miktar;
    }

    getBakiye() {
        return this.#bakiye;
    }
}
// user.#bakiye -> HATA
KALITIM

Inheritance & Super

extends ve super anahtar kelimeleri ile miras alma işlemi.

class Personel {
    constructor(ad) { this.ad = ad; }
}

class Muhendis extends Personel {
    constructor(ad, dil) {
        super(ad); // Base class çağrısı zorunlu
        this.dil = dil;
    }
}
ÇOK BİÇİMLİLİK

Polymorphism

Farklı sınıfların aynı metod ismine (imzasına) sahip olup farklı işler yapabilmesi.

class Kare {
    ciz() { console.log("Kare çizildi"); }
}

class Daire {
    ciz() { console.log("Daire çizildi"); }
}

const sekiller = [new Kare(), new Daire()];
sekiller.forEach(s => s.ciz());
SOYUTLAMA

Abstraction

Abstract class JS'de yoktur ama new.target ile simüle edilebilir.

class BaseAPI {
    constructor() {
        if (new.target === BaseAPI) {
            throw new Error("Abstract class new'lenemez!");
        }
    }
}
PATTERN

Interface (Simülasyon)

Metodun içi boş bırakılıp hata fırlatılarak implementasyona zorlanır.

class ILogger {
    log(msg) {
        throw new Error("log() metodu yazılmalıdır!");
    }
}
BEST PRACTICE

Composition over Inheritance

Sürekli miras almak kodu kırılgan yapar. Yetenekleri parçalayıp birleştirme (Factory) yöntemidir.

const ucabilir = (o) => ({
    uc: () => console.log(`${o.ad} uçuyor`)
});

const RobotFactory = (ad) => {
    const robot = { ad };
    return Object.assign(robot, ucabilir(robot));
}
