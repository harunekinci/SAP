Sistemde bir projede değişiklik yaptıktan sonra dev sisteme deploy edilmeli ve ardından kontrollerle test ve canlı sistemlere taşınmalıdır.

Proje çekildikten ve gerekli değişiklikler sağlandıktan sonra deploy adımına geçilir.

![image](https://github.com/user-attachments/assets/e099b4a7-766b-4680-a1c6-0a1e426ced74)




Mevcut projeye;

	1. Sağ tıkla, deploy alanında en üstteki seçeneğe tıkla.

	Önemli Not :  Proje üzerinde başka bir geliştirici/danışman request açmış locked by hatası alırsınız ve o request taşınmadan deploy işlemi yapılamaz. Bu durumda danışmandan veya geliştiriciden bilgi alınarak requesti taşınmalıdır.
	
	1. Eğer projede herhangi bir request yok ise fiori dev üzerinden request oluşturmalısınız.

![image](https://github.com/user-attachments/assets/c97d97e0-7eea-4e11-9ed9-db1366a9a0d5)

	
	
	

Proje daha önceden sistem varsa otomatik olarak update zaten seçili olarak gelir.

Next butonuna tıklyarak diğer adıma geçin.

![image](https://github.com/user-attachments/assets/a3de6b07-2fc6-4fff-a05c-42090b72e5a5)



Burada locked by request yok ise next diyerek request seçme adımına geçiniz.

![image](https://github.com/user-attachments/assets/679104c9-389f-493d-a41a-98d58eb05c4b)


Bu alanda ilk kırmızı kutuda request oluşturduysanız onun numarasını girebilirsiniz.

Veya 2. alanda kırmızı kutuda request listenizden seçebilirsiniz.

Veya 3.kutuda create request tikleyerek açıklama metnini ekleyerek o alanda request oluşturabilirsiniz.


Bu işlemi yaptıktan sonra next -> ok diyerek süreci bitirebilirsiniz.
