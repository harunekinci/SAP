	• ORION Kurulu Olmalıdır.

![image](https://github.com/user-attachments/assets/9971610d-2baf-4523-b512-06288f8020df)

	2. Import alanından Application from sapui5 repo seçilmelidir. [ Burda Biraz Bekletebilir ]

![image](https://github.com/user-attachments/assets/b97c4ea0-4391-4a5f-854e-4e949f2da41f)


	1. Gelen Pop-up`ta dev bilgileri girilmelidir.
	2. Sonrasında yukarıdaki sayfada proje adına veya açıklamasına göre arama yapılmalıdır.
	3. Seçtikten sonra Ok diyebilirsiniz.

Proje başlatılamadan önce uygun versiyon seçilmelidir. 1.84 sürümleri bizim sistemimiz için uygundur.

Proje açılmadığı durumlarda manifest json üzerinden parametreler bakılmalıdır, bazı durumlarda sayfalar url kısmında parametre bekleyebilir ( Örnek : Satış İşlemleri ).
