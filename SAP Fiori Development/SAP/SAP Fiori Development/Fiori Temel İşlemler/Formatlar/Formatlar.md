
Servislerden istek atarken bazı alanlarda özel format uygulamanız gerekir. 

	1. Tarih - DATETIME
	datetime'2019-01-17T00:00:00' format bu şekilde olmalıdır eğer bu alan boş gidecek ise null yazabilirsiniz.
	
	
	2. GUID16-GUID
	8-4-4-4-12 bu formatta olmalıdır. Eğer bu alan boş olacak ise tüm alanlara 0 yazılabilir. 
	00000000-0000-0000-0000-000000000000 : Örnek Boş GUID
